# Halcyon

A brand site for a made-up seaside retreat. There are no images in the repo. Everything you see is drawn in code.

https://bxzex.github.io/halcyon/

The hero is a WebGL shader that warps noise until it looks like moving water. The room pictures are painted onto canvases at load time: sky, sun, dune ridges, marram grass and a bit of film grain, with a different seed for each card.

Smooth scrolling is frame rate independent. The first version wasn't, and on a slow machine it never caught up with the scrollbar.

The booking form validates properly but doesn't send anything.
